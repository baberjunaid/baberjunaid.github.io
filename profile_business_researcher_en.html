Selected Research Projects

Applied research projects spanning AI for governance, intelligent automation, multilingual analytics, and robotics.

Large Language Models for Low-Code/No-Code Automation

Designed LLM-based workflows for domain-specific model generation and intelligent automation in low-code/no-code environments.

Methods: Prompt engineering, grammar-constrained generation, model evaluation pipelines.

Smart Surveillance & AI Monitoring Systems (Government Project)

Built an AI-enabled surveillance architecture integrating IP cameras, recognition pipelines, and operational dashboards for public-sector deployment.

Methods: Computer vision, face recognition workflows, web-based monitoring.

Multilingual Sentiment Analysis for Policy Intelligence

Developed multilingual sentiment analysis resources for English, Urdu, and Roman Urdu, including benchmark dataset construction and model training.

Methods: NLP classification, low-resource language handling, social media analytics.

Human Motion Prediction for Intelligent Systems

Implemented embedding-based prediction models for human motion in shared workspaces to support safer human-robot interaction.

Methods: Vector embeddings, trajectory quantization, nearest-neighbor retrieval.

3D LiDAR Object Detection Framework

Developed a lightweight 3D object detection method balancing real-time performance and detection quality on constrained hardware.

Methods: Adaptive clustering, 3D point spatial histograms, compact feature modeling.
